quorum. component specimens

The eight components the requirements name, drawn from the library rather than from a mock. Nothing on this page picks a colour, a size or a hue: every value is a token and every phase colour comes from the phase name.

Participants

identity chip · hue is keyed on (name, harness), so it survives a reconnect · a human gets a square dot and --id-human · status="waiting" pulses: blocked in wait_for_events

message row · challenge draws the coral rail · system and claim rows are mono and unattributed · the private refusal carries no seq, because no event carried it

Deliberation

phase stepper · Failed replaces the terminal step — the rail never shows a path not taken, and never grows a fifth box

proposal card · options are listed and the tally is not — during voting a visible count is the anchoring hidden ballots exist to prevent

vote chip · a tally row, and a recorded ballot citing its index · a v0 ballot is an option index, never a stance — "add it now" versus "defer to v1" has no against

during voting · cast-but-hidden above, no-ballot-yet below · the roster is drawn cast/not-cast per eligible voter and never the choice, because turnout is what closes the phase · neither chip is a button: nothing announces itself pressable unless it answers the keyboard

dissent badge · violet, never red: dissent is a record, not an error · never truncated, never behind a "show more"

Records

decision record · the one light surface: warm paper, serif, a real shadow · ink is the live present, paper is the permanent past

failure record · failure is an outcome with a typed reason (protocol D8), on the same paper · everyone who never cast is named, because "3 of 6 ballots" is not a record of what happened

Composer

composer · the participant's one input — room, DM and challenge window use this and nothing else · Send is inert until the draft has something in it · actions are words, at most one in brass

challenge window · the hint becomes the considerations rule, because a stance typed here is public voting and hidden ballots would then protect nothing (§6) · phase word in its hue, hued top edge, deadline in mono

dm thread · no phase, no actions · an explicit hint replaces the keyboard line

disabled · the reason is the one thing that must not go missing: a quiet field with no explanation is this component's only real failure mode

private notice · a refusal came back to you alone, so it is a private row — dashed rail, no seq, footnoted — and never an error banner · it names the holder and ends in the next action
