# Quorum decision records

Repo-scoped architecture decisions (`ADR-NNNN`), following the record shape
of the org's [ENG series](https://github.com/qwts/playbook-engineering/tree/main/docs/decisions).
Cross-repo decisions belong there, not here — if exactly one repo would have
to change, it is an ADR; otherwise it is an ENG record. Records are never
deleted or rewritten after acceptance; they are superseded.
